# 念匣（Nianxia）

> 一个住在你电脑里的 AI 陪伴：人设可以捏、记忆可导出、聊得越久越懂你。
> 本地自托管 · 数据零上传 · 开箱即用

## 这是什么？

念匣是一个**跑在你自己电脑上**的 AI 陪伴应用：

- **开箱即用**：下载安装包，装完就能聊——自带本地小模型（Qwen3.5-2B），不联网、不要 Key、不要显卡
- **捏角色**：角色卡系统，兼容酒馆（SillyTavern）的 chara_card_v2 卡，导入导出随你走
- **她真的记得**：分层记忆系统，说过的事她会记住、会想起、会写进日记一样的「领悟」里
- **随时带走**：一键导出备份和「回忆读本」，你的数据永远是你的
- **社交通道**（可选）：把她接到 Telegram / QQ / 微信，手机上也能聊，还能给不同通道配不同角色
- **画图与朗读**（可选）：按角色锁脸生图、按角色音色朗读

## 安装（小白版，1 分钟）

**只需要一个文件**：去 [Releases](../../releases) 下载 `念匣_x.x.x_x64-setup.exe`，双击安装。

装完第一次打开，稍等十几秒（她在搬家进你的电脑），就能开始聊天了。
不需要注册、不需要联网、不需要任何配置。

> 安装包约 2GB，因为里面装着她的「大脑」（本地模型）——这是她能完全离线陪你的原因。

## 第一次使用

1. **起个名字**：首次打开会引导你给「她」起名字、写两句人设（也可以直接跳过用默认的「念念」）
2. **开始聊天**：就像发微信一样。她说错话了可以点气泡下的「重抽」换一版
3. **捏更多角色**：点右上角人物图标 → 角色卡，可以新建、导入酒馆卡、AI 一句话代笔整卡
4. **让她记住你**：聊天中点气泡下的「记住」，她会认真记下

## 常见问题

**Q：完全离线能用吗？**
A：能。本地模型离线可用。如果你配置了云模型或画图服务，只有对应功能会联网。

**Q：我的聊天记录存在哪？**
A：全部在你电脑的 `文档/念匣` 文件夹里，纯本地，没有任何东西会上传。

**Q：配置云模型会更聪明吗？**
A：会。设置里填一个 OpenAI 兼容的 API（任何厂商都行），聊天质量立刻上一个台阶。本地小模型胜在免费、离线、隐私。

**Q：手机能玩吗？**
A：可以曲线救国——在设置里把 Telegram/QQ/微信通道打开，手机上用这些 App 和她聊。

**Q：发图片给她她能看吗？**
A：需要视觉组件（mmproj，约 0.7GB）。安装包为了控制在 2GB 内没有内置它；源码安装方式会自动下载。没有它她会诚实告诉你「我现在看不到图」。

**Q：想卸载？**
A：正常卸载即可。你的聊天数据在 `文档/念匣`，卸载不会删它，想彻底清除手动删那个文件夹。
